ConsultaMX v2.3.0: RPA CURP hands-free. On cache miss, the app launches RENAPO automatically, fills CURP, submits the form without user clicks using multiple DOM/form strategies, polls the result, persists evidence, and returns to the app. The WebView stays hidden while automation is possible and is only revealed if the government site requires an unavoidable human verification such as CAPTCHA. No CAPTCHA bypass is implemented.
